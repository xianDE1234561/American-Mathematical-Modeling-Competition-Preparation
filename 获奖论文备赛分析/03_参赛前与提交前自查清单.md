# 获奖论文启发下的备赛与提交自查

本清单依据 2021—2025 论文阅读归纳，是工作检查工具，不是官方评分表。正式规则以当届 [COMAP 指南](https://contest.comap.org/undergraduate/contests/mcm/instructions.php) 为准。

## 开始建模前

- [ ] 已把题目的每个要求转成明确输出：预测、解释、评价、优化、建议或信件。
- [ ] 已定义评价对象、可用数据、决策时可知道的信息和主要约束。
- [ ] 有一张数据来源表；缺失值、实体名称、时间范围、单位和数据含义已检查。
- [ ] 每个重要假设有理由，知道它影响什么公式或结论。
- [ ] 有一版能运行的基础模型，知道复杂模块要解决什么缺口。

## 获得第一版结果后

- [ ] 每个主要小问都有结果；没有结果的部分清楚说明现状和原因。
- [ ] 单位、符号、概率范围、资源守恒及其他约束未被违反。
- [ ] 没有将未观测或预测值误写成真实数据。
- [ ] 测试数据和训练、选参数据的使用边界明确；时序或同源样本没有泄漏。
- [ ] 有简单基线、对照情景或现实量级检查，比较条件一致。
- [ ] 指标适合任务：不是所有问题都用准确率或 R²。
- [ ] 敏感性分析交代参数、范围、输出指标、结论变化和实际含义。
- [ ] 区分决策变量、估计参数和外部情景；没有把“不敏感”当成普遍优点。
- [ ] 有不利案例或边界讨论；解释可能原因时没有伪称已证明因果。
- [ ] 启发式求解结果没有在缺少证明时被称为全局最优。

## 写作与图表

- [ ] 方法写清“为什么适合、怎么实现、解决什么”，没有只列算法名称。
- [ ] 数字能追溯到具体数据版本和运行结果；摘要、正文、表格一致。
- [ ] 每张重要图都有单位、图例和解释；图中的发现用于回答题目。
- [ ] 建议说明对象、行动、依据、条件与代价，没有停留在空泛口号。
- [ ] 局限写成“限制—影响—改进”，而不只是“时间有限、数据不足”。
- [ ] 摘要已在主要结果确定后定稿，包含方法、结果和意义。
- [ ] 队友只读摘要，也能复述主要贡献和结论的可信范围。
- [ ] “证明、显著、最优、准确、普适”等强词有相应依据，没有把作者自评当证据。

## 当前格式规则与最终核对

以下规则核验于 2026-10-09，来源为当前 COMAP 指南；提交前须再检查当届更新。

- [ ] 主报告至多 25 页，摘要、参考文献和附录计入；未误用历年全文总页数作模板。
- [ ] 如使用 AI，已按当届政策在正文和参考文献中披露，并另附 Report on Use of AI。
- [ ] 英文报告、摘要第一页、可读字号、页眉队号与页码等符合当届指南。
- [ ] 报告中未出现学生、指导教师或院校等识别信息；只保留允许的队号。
- [ ] 最终 PDF 已实际打开；没有截断图表、缺失公式、乱码或空白输出。
- [ ] 在当届工作截止时间前完成修改，并预留提交余量。

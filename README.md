# American Mathematical Modeling Competition Preparation

This is my personal preparation and study repository for the **Mathematical Contest in Modeling (MCM)** and **Interdisciplinary Contest in Modeling (ICM)**. It brings together historical problems, selected Outstanding Winner papers, reading notes, practical checklists and an independent modeling exercise.

## Contents

| Folder | Contents |
|---|---|
| `历年官方资料_2021-2025` | 30 official problem PDFs, 9 official data ZIPs, 30 official result reports and 45 selected O-award papers, with source indexes |
| `获奖论文备赛分析` | Structural screening of 45 papers, focused reading of 18 examples, preparation advice and page-level evidence |
| `真题` | Ordered 2025 problem folders; the complete D data are supplied as an official ZIP in the historical archive |
| `C题_Codex独立项目` | Python code, official inputs, computed outputs, validation evidence and report sources |

Most detailed study notes are in Chinese. The paper study is based on a selected sample and does not establish official scoring weights, causal reasons for awards or a guarantee of winning. Model results in the independent exercise are study outputs and should be read with their limitations.

## Sources and rights

Problems and result reports originate from COMAP. Selected paper PDFs were obtained from a public third-party collection and matched against official award records; some copies contain third-party watermarks. They are not COMAP-authored standard answers. Original authorship, institution credits, public award information and public dataset names are retained. Third-party materials remain subject to their original rights; this repository does not grant a blanket redistribution license.

## Packaging and privacy

This upload uses a separately prepared copy. User-specific local paths and detected account/contact markers have been removed; document and image metadata have been cleaned; repository links use portable paths. Virtual environments, credentials, caches, obsolete report backups and local operating/audit records are excluded. Original local files are unchanged. The first Git commit uses a neutral author and email.

GitHub repository ownership is account-linked; cleaning file contents cannot make the repository owner's GitHub account anonymous.
